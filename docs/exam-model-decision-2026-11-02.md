# 診察の要約のモデル：3.6 のまま（2026-11-02 の判断と比較の記録）

## 判断
**診察の要約の既定は Gemini 3.6 Flash 先頭のまま（`app/lib/gemini-models.js` の `EXAM_SUMMARY_MODELS`）。変えない。**

- 院長の判断（指示書 exam-model-decision・2026-11-02）
- 3.8 にするなら、**先に疾患見出しのルールを強めてから測り直す**。測らずに変えない。
- 他の画面（議事録・セミナー・カウンセリング分析・ジャーニーマップ・36 ルート）は共通の順番 `GEMINI_MODELS`（3.8 → 3.7 → 3.6 → 3.5 → 2.5）。

## 比較の方法
- **書き起こし:** 実際の診察 10 本。候補 300 本から選び、採用薬が出てくるもの 8 本、出てこないもの 2 本。
  - 文字数は 403〜3063 字。
  - 書き起こしはメモリ上で読んだだけで、ディスクには残していない。
- **プロンプト:** 本番の「⚖ 3.6/3.8 比較」ボタンと同じもの（4897 字）。採用薬の一覧と疾患見出しの書式を含む。
- **回数:** 各本 5 回。3.6 と 3.8 は交互の順で呼んだ。
- **呼び方:** 本番の API を直接呼んだ。本番の records は作っていない。
- **3.8 の指定:** 診察の 2 つめの選択肢（中の指定は `gemini-3-7-flash`）。応答の modelVersion は gemini-3.8-flash。

### 結果の見方
- **薬剤名の誤りの疑い**
  - 両方に、薬でない「ガングリオン」「チューブ」が入っています。
  - それを除くと、3.6 は ヘパリン・ゼビアックスローション・ビブラマイシン・ベピオゲル、3.8 は ヘパリン・ディフェリンゲル です。
- **疾患見出しの崩れ（3.8）**
  - 部位のない「湿疹」が出ました（正しくは「体部湿疹」。5 回中 4 回）。
  - 「乾燥肌（皮脂欠乏症）」が出ました（正しくは「皮脂欠乏性湿疹」）。
  - 部位のない見出しは、5 分類の部位カテゴリを入れた作業を無効にしてしまいます。
- 「背部湿疹 → 体部湿疹」は両方に出ました。

## 測り直すとき
- **スクリプト:** その時の作業用フォルダ（scratchpad）に置いた `exam-compare.mjs`（リポジトリには入っていない）。中身は、本番の比較ボタンのプロンプトを捕まえて `/api/summarize` を交互に呼び、上の 5 つの指標を数えるもの。
- **本番の鍵:** `docs/runbook-prod-env.md` の方法で、メモリ上だけで渡す。
