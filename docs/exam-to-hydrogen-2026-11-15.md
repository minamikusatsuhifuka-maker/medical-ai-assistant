### 見出しのプロンプトを強める案（未実施・院長の判断待ち）
崩れはどちらのモデルも「部位のない湿疹」と「5 分類にない部位」です。`DISEASE_HEADING_PROMPT_RULES` の 5 に、次を足す案です。
```
   部位の振り分け（必ずこのどれかにする）:
   頭・頭皮・耳・首より上の髪の生え際 → 頭部 / 顔・まぶた・口のまわり → 顔面 / 手・指・手首 → 手
   首・胸・背中・お腹・腕・脚・足 → 体部 / 陰部・お尻・股 → 陰部・臀部
   部位が会話から分からないときは「体部湿疹」と書く。「湿疹」「皮膚炎」だけの見出しは書かない。
   誤: 湿疹 / 首の湿疹 / 首湿疹 / 腕の湿疹   正: 体部湿疹
```
- 振り分けは、今の `BODY_CATEGORY_MAP`（首 → 体部・耳 → 頭部・足 → 体部）と同じにしてある。
